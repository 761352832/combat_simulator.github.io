# 橫版武道模擬格鬥器 (Fighting Simulator) 使用指南

本格鬥模擬器是一款以 HTML5 Canvas 與 Web Audio API 打造的二人橫版古裝武俠格鬥模擬應用，具備完整的數值演算、武力值評估、古風裝束動作演繹、最後一擊慢動作特寫以及時間軸戰鬥回放功能。

---

## 🌟 核心功能特色

### 1. 人物數據與武力值系統 (Combat Stats & Power Rating)
- **核心戰鬥數值**：
  - **生命力 (HP)**：影響戰鬥續航能力。
  - **物理外功 (ATK)**：決定基礎攻擊造成的物理傷害。
  - **護體罡氣 (DEF)**：提供傷害減免防護。
  - **速度身法 (SPD)**：影響出手先後順序與主動搶攻機率。
  - **暴擊率 (CRIT%)**：造成 1.85 倍致命暴擊傷害的機率。
  - **閃避率 (DODGE%)**：完全避開對手攻擊的機率。
  - **怒氣 / 真氣 (Qi/Rage)**：受創與攻擊時積累，滿 50 點施放「連段絕技」，滿 100 點爆發全螢幕「極限奧義」。
- **實時武力值測算**：系統依據人物各項攻防數值實時計算綜合「武力值」，並劃分武道境界（如：EX 絕世武神、SSS 一代宗師、SS 先天名宿等）。

### 2. 人物模型與古風裝束細節 (Ancient Wuxia Character Aesthetics)
- **男女雙體態古裝模型**：
  - **男俠模型**：束髮金冠、嵌玉髮簪、英挺劍眉、對襟輕甲長袍、交領右衽金絲滾邊、獸面金龍腰扣、側懸白玉雙環佩、精鋼皮製護臂束腕與高筒雲頭戰靴。
  - **女俠模型**：修身齊腰漢服、交領右衽雪白領緣、垂肩鬢角仙姿碎髮、高馬尾配銀月雕花步搖簪與長紅綢髮帶、額間硃砂花鈿、和田翠玉雙魚珮、飄逸雙色宮絛流蘇與多褶下裳仙裙。
- **古典兵器與長穗紅纓**：
  - **刀劍兵器**：冷光血槽唐橫刀、仿古鏨花太極銅刀鐔與飄揚長紅綢劍穗配小金鈴。
  - **長柄槍矛**：白蠟木雕紋槍桿、濃密血色紅纓（紅纓隨動作飄動）與破甲三稜槍尖。
  - **拳掌空手**：金絲纏絲護指手甲與真氣流轉光芒。

### 3. 頭像置入與系統古風頭像生成 (Avatar System)
- **置入自訂圖片 (Upload Image)**：點擊「📁 置入自訂圖片」，選取本機中的任何圖片或照片，系統自動適配並裁切為角色戰鬥頭像。
- **系統隨機古風生成 (System Generator)**：點擊「🎲 系統生成頭像」，系統內建之古風演算法會依據男女體態隨機繪製專屬的古裝動漫武俠頭像（包含交領右衽長袍、束髮金冠/步搖髮簪、刺繡抹額、硃砂花鈿、面部鬢角與護心鏡/玉珮）。
- **預設宗師庫 (Presets)**：內建多款高精細預設古裝武者頭像（蒼藍武尊、赤煞狂戰、金剛羅漢、碧影刺客、烈纓女將、霸王槍尊），一鍵快速套用。

### 4. 二人橫版對戰演繹與慢動作特寫 (2D Arena & Slow-Motion)
- **流暢 60FPS 動作幀**：包含待機呼吸（Idle）、起手聚氣（Startup）、疾步突進（Dash）、直拳揮劈、護體招架（Guard Shield 2.0s）、殘影閃避（Dodge）、受創硬直（Hit Reaction）、極限奧義（Ultimate）、氣竭暈眩（Recovery Stiff）與倒地潰敗（K.O.）。
- **最後一擊慢動作特寫 (Finishing Blow Slow-Mo)**：致命一擊時自動切換 0.25x 慢動作電影鏡頭，並伴隨打擊鏡頭縮放震動與金色火花粒子。
- **三款動漫武俠實景場景**：玄天武鬥場、清風翠竹林、滄海驚濤岸，具備動態落葉飄浪環境粒子。

### 5. 戰鬥回放與勝負競猜系統 (Battle Replay & Betting Market)
- **任意時間軸跳轉與逐動剖析**：隨時拖動「🎞️ 回放進度」時間軸滑桿，任意跳轉至特定回合，重溫關鍵戰況，並可一鍵重放最後一擊慢動作。
- **靈石盤口與競猜**：依雙方實時武力值精算動態賠率（P1獨贏、P2獨贏、平局超高倍率），賽後自動發放獎勵靈石，支援連勝統計與宗門救急金。

## 🚀 快速上手步驟

1. **設定角色與古裝體態**：
   - 點擊「👦 男俠模型」或「👧 女俠模型」切換古風體態，挑選「🥊 拳掌」、「🗡️ 刀劍」或「🔱 槍矛」兵器。
   - 拖動屬性滑桿調整 HP、ATK、DEF、SPD、暴擊率等數值，右上方武力值即時刷新。
2. **更換或生成頭像**：
   - 點擊「📁 置入自訂圖片」上傳本機圖片，或點擊「🎲 系統生成頭像」由系統繪製專屬古風頭像。
3. **進行勝負預測 (可選)**：
   - 在中央「擂台勝負競猜」區域選擇您看好的宗師並選擇押注籌碼。
4. **展開對決與重溫慢動作**：
   - 點擊頂部「⚡ 開始模擬對決」按鈕展開激烈對決，戰鬥結束後可點擊「🎬 重溫最後一擊慢動作」或拖動進度條重溫每一步戰況！
